# EPIC-11 STORY-11.2 — Sources (list/create/edit, per-kind forms, test-connection) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Let a session admin manage a tenant's sources from the admin UI — list (status/last-sync/next-sync/error), create/edit via schema-driven per-kind forms, test-connection, sync, delete — over a new session-authenticated, tenant-scoped API that reuses the existing sources service.

**Architecture:** A `RequireTenantAccess` session middleware resolves+authorizes the tenant from `/admin/tenants/{id}/…` and injects it into the context the existing `internal/cp/sources` handlers already read, so those handlers are reused verbatim (ADR-0075). A session, platform-global `GET /admin/connector-kinds` returns per-kind form-field descriptors (drift-guarded against `ValidateConfig`) that the Next UI renders into forms. All via the BFF (`/bff/admin/…`).

**Tech Stack:** Go (net/http, pgx, existing `internal/cp/{sources,auth}`, `internal/connector`, `internal/tenant`); Next.js App Router + TS + Tailwind + TanStack Query; Vitest/RTL; Playwright.

**Spec:** `docs/specs/SPEC-11-admin-ui.md` §10 (+ `docs/adr/0075-session-admin-tenant-scoped-api.md`)

## Global Constraints
- Reuse the existing `sources.Handlers`/`Service` and `SourcesValidator` — do NOT duplicate source CRUD/test logic. The only new server auth path is `RequireTenantAccess`.
- Tenant reached only via the resolver → `*tenant.DB` where tenant content is touched (ADR-0003); the sources service already respects this. Session token never logged; CSRF on mutations (SPEC-09 §3).
- Authz: platform-admin OR the session user's `tenant_members` role for `{id}` — any role for GET, the SPEC-02 §4 role (`roles.go` permission matrix) for writes. Inaccessible/unknown tenant → **404** (no existence leak). Platform-admin acting on a non-member tenant → audited `impersonation=true`.
- Browser calls go through the BFF (`/bff/admin/tenants/{id}/…`, `/bff/admin/connector-kinds`) — already allow-listed (`v1`/`admin`). No CORS.
- New/changed Go files: `mise run lint` 0 new issues (10 pre-existing baseline stays; `web/` excluded). Web: `npm run build` + `npx vitest run` green. Commit messages: no co-authored/signed-off trailers. Every change carries **ISSUE-0059**.

**Interfaces:**

- Produces: `AuthzService.RequireTenantAccess(perm Permission) func(http.Handler) http.Handler` — reads `r.PathValue("id")`, resolves the principal, allows platform-admin or a role satisfying `perm` (per `roles.go`), injects `tenant.WithTenantID`, audits impersonation for cross-tenant platform-admin, else 404 (unknown/non-member) or 403 (member lacking `perm`). Mounted routes reusing `sources.Handlers`.

  - On allow: `ctx = tenant.WithTenantID(ctx, parsedID)`; `next.ServeHTTP(w, r.WithContext(ctx))`.

- [ ] **Step 4: Run → PASS**
- [ ] **Step 5: Mount the routes** in `internal/api/router.go` — add a helper mirroring `platformAdmin`:
```go
	tenantAccess := func(perm auth.Permission, h http.Handler) http.Handler {
		return chain(handlerOr(h), mw(d.RequireSession), mw(d.RequireTenantAccess(perm)))
	}
	mux.Handle("GET /admin/tenants/{id}/sources", tenantAccess(auth.PermSourcesRead, d.SourceList))
	mux.Handle("POST /admin/tenants/{id}/sources", tenantAccess(auth.PermSourcesWrite, mustCSRF(d, d.SourceCreate)))
	mux.Handle("GET /admin/tenants/{id}/sources/{sourceId}", tenantAccess(auth.PermSourcesRead, d.SourceGet))
	mux.Handle("PATCH /admin/tenants/{id}/sources/{sourceId}", tenantAccess(auth.PermSourcesWrite, mustCSRF(d, d.SourceUpdate)))
	mux.Handle("DELETE /admin/tenants/{id}/sources/{sourceId}", tenantAccess(auth.PermSourcesWrite, mustCSRF(d, d.SourceDelete)))
	mux.Handle("POST /admin/tenants/{id}/sources/{sourceId}/sync", tenantAccess(auth.PermSourcesWrite, mustCSRF(d, d.SourceSync)))
	mux.Handle("POST /admin/tenants/{id}/sources/{sourceId}/test", tenantAccess(auth.PermSourcesWrite, mustCSRF(d, d.SourceTest)))
```
  NOTE: the existing handlers read `r.PathValue("id")` for the **source** id. These routes use `{id}` for the tenant and `{sourceId}` for the source — so either (a) the sources handlers must read `{sourceId}` here, or (b) keep the source param named `id` and name the tenant param differently (`{tenantId}`). **Decision:** name the tenant segment `{tenantId}` in these routes and keep the handlers' existing `id`=source-id, and have `RequireTenantAccess` read `r.PathValue("tenantId")`. Adjust the Step-3/5 code to `{tenantId}` accordingly. (Confirm the sources handlers use `r.PathValue("id")` for the source and leave that untouched.)
- [ ] **Step 6: Wire Deps** in `internal/cli/api_server.go`: set `RequireTenantAccess: authz.RequireTenantAccess` and reuse the already-built `sourceHandlers` for the new Deps fields (or reuse the existing `SourceList`… fields directly if the router references them for both surfaces).
- [ ] **Step 7: Verify + commit** — `mise run build && go test ./internal/cp/auth/ ./internal/api/ && mise run lint` (0 new). Create **ISSUE-0059** (Feature, In progress, STORY-11.2, FR-ADM-01, ADR-0075). Commit `Add session tenant-scoped sources routes via RequireTenantAccess (STORY-11.2)`.
